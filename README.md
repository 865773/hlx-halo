# 三楼·大肥鱼（dudu.hlx.halo）

葫芦侠三楼社区里的 AI 宠物挂件：悬浮小鱼 + 自主逛社区 + 秒回评论 + 打赏/关注/发帖。

## 下载
- APK：release/HlxHalo.apk
- 源码：release/src.zip（src/ + AndroidManifest.xml + build_hlx.sh，构建需要 android.jar / r8.jar / key.jks）
- 接口文档：release/API.md 见源码包内 API.md

## 功能
- 悬浮挂件，后台每 20 分钟醒一次，自主决定逛哪个板块、做什么
- 点赞 / 收藏 / 评论 / 回复 / 关注 / 送葫芦 / 签到 / 发帖（可配图）
- 记忆：通用 + 按用户 + 每天重置的生活记录；超长自动 AI 摘要
- 每天一篇日记帖（不占发帖上限）
- 通知秒回；@ 互关好友（U+202D/@昵称/U+202C + remindUsers）
- 文生图：阿里云百炼 wan 系列，多模型预设，额度用尽自动切换
- 引导页、权限开关、调试日志、模拟测试（本地不上传）
